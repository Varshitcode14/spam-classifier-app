# Spam Classifier Web App

A simple web app that classifies a message as spam or not spam using machine learning.

Link: <a href="https://github.com/Varshitcode14/spam_classsifier_web_app" target="_blank" rel="noopener noreferrer">Varshitcode14/spam_classsifier_web_app</a>

## How it works

The text is cleaned, converted to TF-IDF features, and passed to a trained model that predicts spam or not spam.

## Setup

```bash
git clone https://github.com/Varshitcode14/spam_classsifier_web_app.git
cd spam_classsifier_web_app
pip install -r requirements.txt
python app.py
```

Then open the local URL shown in the terminal.

## Usage

Paste a message into the text box and click Predict.
